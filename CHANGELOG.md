# Changelog

All notable changes to KIRA are documented here.

## [1.1.0] - 2026-08-17

### Added

- Kira Dock with contextual AI assistance, file attachments, and provider routing.
- Vision-assisted reference tagging for OpenAI-compatible, Anthropic, Gemini, and Ollama providers, with local fallback behavior.
- Direct node editing, richer details overlays, frames, stickers, and improved node-link workflows.
- Responsive tag overflow and filtering for dense reference libraries.

### Changed

- Reworked the Library into a compact, image-forward browser with clearer tag controls.
- Improved node interactions, selection behavior, morphing, link paths, and canvas navigation.
- Unified the macOS shell, capture surfaces, drawers, and chrome around the current translucent material system.

### Fixed

- Improved save reliability, capture delivery, drag and drop, and Pinterest image handling.
- Fixed several canvas hit-testing, link affordance, panel overlap, and responsive layout issues.
- Refined Safari and Chrome extension packaging and inactive-app states.

## [1.0.1] - 2026-07-27

- macOS chrome, canvas geometry, save reliability, temporary tab names, resizing, and Safari extension fixes.

## [1.0.0] - 2026-07-27

- First public Apple Silicon release from VX Studio.
