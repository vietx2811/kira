# KIRA 1.0.1

KIRA 1.0.1 is a focused macOS polish and reliability release from VX Studio.

![KIRA 1.0.1 workspace](https://raw.githubusercontent.com/vietx2811/kira/v1.0.1/docs/assets/workspace-overview.png)

## What’s new

- Native translucent macOS chrome for the top bar, sidebar, and drawers.
- Cleaner selected tabs, inset canvas corners, and window-owned rounding and shadows.
- Responsive canvas controls when the Library or Inspector is open.
- Reliable Save and Save As behavior for new `.kira` files.
- Stable temporary names for every new tab.
- Easier bottom-right window resizing and non-overlapping drawer controls.
- Safari Extension 1.0.1 embedded and registered with the KIRA app.

## Install on Apple Silicon Mac

1. Download `KIRA-1.0.1-macos-arm64.zip` and extract it.
2. Open Terminal in the extracted folder.
3. Run:

   ```bash
   chmod +x sign-kira.sh
   ./sign-kira.sh
   ```

4. Move `KIRA.app` to `/Applications`.
5. Open KIRA. To enable Safari capture, go to **Safari → Settings → Extensions** and enable **KIRA**.

The included signing script creates an ad-hoc signature for the current Mac. Developer ID signing is also supported; see `HUONG-DAN.md` in the archive. This release is not notarized by Apple.
