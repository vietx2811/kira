# KIRA 1.1.0

KIRA 1.1.0 is a feature release from VX Studio focused on faster visual research, clearer node editing, and contextual AI assistance.

![KIRA 1.1.0 workspace](https://raw.githubusercontent.com/vietx2811/kira/v1.1.0/docs/assets/workspace-overview.png)

## What’s new

- Kira Dock provides contextual AI assistance with file attachments and multiple provider routes.
- Optional vision-assisted tagging can analyze reference images through OpenAI-compatible, Anthropic, Gemini, or Ollama providers, while retaining local fallback behavior.
- Node editing, details overlays, frames, stickers, links, selection, and canvas navigation are more direct and predictable.
- The Library is more compact and image-forward, with responsive tag overflow and filtering.
- Capture, drag and drop, Pinterest handling, project saves, and browser extension packaging are more reliable.
- macOS chrome, drawers, capture surfaces, and canvas geometry use a more unified translucent material system.

## Install on Apple Silicon Mac

1. Download `KIRA-1.1.0-macos-arm64.zip` and extract it.
2. Open Terminal in the extracted folder.
3. Run:

   ```bash
   chmod +x sign-kira.sh
   ./sign-kira.sh
   ```

4. Move `KIRA.app` to `/Applications`.
5. Open KIRA. To enable Safari capture, go to **Safari → Settings → Extensions** and enable **KIRA**.

The included signing script creates an ad-hoc signature for the current Mac. Developer ID signing is also supported; see `HUONG-DAN.md` in the archive. This release is not notarized by Apple.
